# BoteraMaster — демо-видео (план)

**Что это:** Telegram-бот для записи клиентов у частного бьюти-мастера; мастер даёт только токен бота, всю инфраструктуру берёт на себя BoteraMaster.
**Для кого:** частные мастера (маникюр, брови, ресницы, волосы, массаж, тату, макияж).
**Отличие:** у каждого мастера свой бот, а не общий бот платформы; серверы, хостинг и поллинг — не его забота.
**Хук:** «Вы — мастер, а не айтишник.»
**Подпись для соцсетей:** Свой бот для записи в Telegram — нужен только токен.
**Тон:** default + немного polished. Спокойная уверенность, тёмная тема, розовый и телеграм-голубой.
**Оговорка:** кода пока нет — интерфейс нарисован по сценариям из docs/spec (демо-концепт MVP). Имена клиентов, цены и время условные.

## Раскадровка (23 с, 120 BPM, склейки на долях)

| # | Время | Сцена |
|---|---|---|
| 1 | 0–3 | Хук: «Вы — мастер, / а не айтишник.» + плашки специализаций |
| 2 | 3–7 | Раскрытие: логотип, «Свой Telegram-бот для записи клиентов». Справа карточка «Бот»: чек-лист минимальной настройки, ввод токена, «Запустить» → статус «Активен». Вступают барабаны. |
| 3 | 7–12.5 | Клиент в боте: категория → услуги (гель-лак + дизайн) → итог и свободное время → 14:00 → «Вы записаны!» |
| 4 | 12.5–16.5 | Календарь мастера: запись 14:00 появляется «через бота»; мастер подтверждает заявку, клиент получает уведомление |
| 5 | 16.5–20 | «Рутина — на автомате»: напоминания, рассылки, штрафы за неявку, доход и расходы + пуш-напоминание |

Переходы: старое уходит, затем входит новое, через фон (без наложения двух кадров).
Звук: мягкий поп-луп в фа мажоре (Fmaj7–Dm7–B♭maj7–C), барабаны с 3 с, тихие щипковые звуки в тон на сообщения и нажатия, в конце звенит аккорд.
